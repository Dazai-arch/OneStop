Student Project Management Platform
🚀 Overview
This project aims to develop a web-based platform for student project management, specifically designed to tackle the common challenges students face while handling academic projects. It offers an all-in-one solution to plan, track, manage, and collaborate on student projects efficiently.

The platform is built to provide a user-friendly dashboard equipped with essential tools that simplify and streamline the project management process, ensuring better productivity and organization.

🎯 Features
Task Scheduler & Management
Efficiently organize, assign, and prioritize project tasks to ensure timely completion.

Collaborator Management
Add and manage team members to collaborate on the same project.

Visual Project Tracking
Includes dynamic Gantt Charts, Bar Graphs, and Line Graphs for visual representation of project progress.

Resource Management
Monitor and allocate resources such as time, materials, and manpower effectively.

Budget Estimation & Financial Monitoring
Tools to estimate project budgets, track cash inflow and outflow, and manage expenses responsibly.

Team Chat Room
A built-in chat system to facilitate real-time communication between team members.
